# springbbe.github.io

Trang gốc của tên miền `springbbe.github.io`. Repo này chỉ có hai mục đích:

- `robots.txt`: Google chỉ đọc robots.txt ở gốc tên miền, nên dòng `Sitemap:` của [BbeTools](https://springbbe.github.io/bbetools/) phải nằm ở đây.
- `index.html`: trang gốc mang tên và dữ liệu có cấu trúc "BbeTools", để Google không hiển thị tên site là "GitHub Pages".

Mã nguồn BbeTools ở repo [springbbe/bbetools](https://github.com/springbbe/bbetools).
